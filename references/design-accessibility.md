# 交互设计、屏幕与无障碍

## 穿戴设备交互

以“快速查看、快速操作”为默认：每屏突出一个主要目标，压缩非必要文字，显示高价值健康/运动/状态数据。遵循 Zepp OS 的 Friendly、Light、Efficient 原则，给点击、保存、错误和连接状态提供明确反馈。

- 根据设备表核实屏幕圆角/形状、状态栏、安全区、屏幕分辨率和物理按键；不要把手机尺寸或 Web 断点直接映射到手表。
- 触控、侧键、数字表冠是不同输入方式。遵从系统统一手势与按键含义；让滚动、返回、确认和选择都能在目标硬件上完成。
- 表盘把时间作为首要信息；为息屏模式减少发光像素和动画，重要信息不放在安全区域以外。
- 在圆屏边缘、方屏状态区和条带屏上检查裁切、行数、长文本、交互目标和滚动距离。
- 颜色、振动、声音和动画都应传递必要状态；避免无意义动画和频繁刷新。

## 视觉一致性

遵循官方视觉规范中的颜色、系统字体、图标、插画、动效、标题、列表、卡片、进度、加载、状态栏与弹窗规则。组件化复用时保持手表上的点击反馈、内容密度与间距一致。

- 让时间、主要指标、单位、状态和操作有明确层级；不要用很小的文字承载关键结果。
- 运动和健康数据需写清单位与时间范围；无权限、无数据和传感器暂不可用要区别呈现。
- 选高对比配色；有意义的信息不要仅用红/绿或颜色差异表达，附加文字、图标或形状线索。
- 按官方 Accessibility 规范核对文字对比度、色觉差异、复杂光照和小屏可读性。

## 国际化和地区格式

先做可伸缩的布局，再填翻译。不要把文案烘焙进图片；长短不同的语言、RTL 布局、默认语言回退、日期顺序、星期首日、时间制式、温度/距离/重量单位和周/月缩写都要覆盖。按语言表和区域标准生成内容，不自行硬编码英文日期格式。

- 设备应用：按 .po 目录命名规范、语言映射和 i18n API / app.json 配置提供文案。
- 表盘：核对设备语言、单位切换、日期和星期/月缩写规范；至少用长文案和负温度测试占位宽度。
